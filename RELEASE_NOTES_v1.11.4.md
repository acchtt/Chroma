# Chroma v1.11.4

This patch improves the update action wording in the Profiles footer.

## UI

- Replaces the passive `Up to date` button label with the action-oriented `Check for updates`.
- Keeps `Checking...` while a check is running.
- Keeps `Update vX` when a newer release is available.
- Restores `Check for updates` after a successful no-update result or a failed check.

## Package

- Compressed self-contained Windows x64 release.
- Portable two-file distribution containing `Chroma.exe` and `Chroma.Agent.exe`.
