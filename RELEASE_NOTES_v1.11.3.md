# Chroma v1.11.3

This layout correction improves the reorganized Profiles page at common desktop window sizes.

## Fixes

- Makes the profile editor body vertically scrollable while keeping Cancel and Save Changes fixed at the bottom.
- Prevents the custom-resolution note and status text from being clipped.
- Reduces the Profiles-page footer height to return more space to the game list and editor.
- Tightens footer padding, action-button height, and logo size while preserving all footer links and update status.
- Slightly compacts editor spacing without changing saturation or custom-resolution behavior.

## Package

- Compressed self-contained Windows x64 release.
- Portable two-file distribution containing `Chroma.exe` and `Chroma.Agent.exe`.
