# Chroma v1.11.10

This release rebuilds the Profiles footer as a dedicated command bar matching the approved mockup.

## Footer redesign

- Replaces the converted legacy footer with a purpose-built single-row layout.
- Enlarges the left Chroma brand block with a 56 px logo, 24 px title, and version/runtime line.
- Adds a centered 52 px divider between branding and utility actions.
- Adds a full-width shield badge labeled **Anti-cheat safe** with the existing architecture disclaimer tooltip.
- Uses consistent 44 px controls for Anti-cheat safe, Website, GitHub, and Check updates.
- Applies balanced spacing, 18 px corner radius, and larger container padding.
- Removes the duplicate far-right logo and all legacy Quick Actions/About footer structure.

## Compatibility

- Keeps all Website, GitHub, and updater actions unchanged.
- Keeps saturation, custom resolution, GPU selection, tray, startup, updater, and anti-cheat behavior unchanged.
- Remains a compressed self-contained two-file Windows x64 package.
