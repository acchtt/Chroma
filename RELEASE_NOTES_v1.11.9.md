# Chroma v1.11.9

This release redesigns the Profiles footer around a single brand block and a clearer anti-cheat safety status.

## Footer redesign

- Moves the Chroma logo into the left brand block beside the app name and version.
- Removes the duplicate logo from the far-right side.
- Adds a shield-style `SAFE` status badge.
- Keeps Website, GitHub, and Check updates aligned as consistent utility actions.
- Adds a tooltip clarifying that SAFE describes Chroma's external GPU-control architecture and is not official anti-cheat certification.
- Uses a subtle divider and balanced spacing across the footer.

## Compatibility

- Does not change saturation, custom resolutions, GPU selection, updater behavior, tray behavior, startup behavior, or anti-cheat architecture.
- Remains a compressed self-contained two-file Windows x64 package.
