# Chroma v1.11.11

This release corrects the footer alignment and updates the brand copy.

## Footer alignment

- Centers the logo, brand text, divider, shield badge, and utility buttons on one shared vertical axis.
- Uses a fixed 64 px inner command-bar height for predictable alignment.
- Centers button icons and labels within consistent 44 px controls.
- Replaces the footer version/runtime line with **created by acchtt** beneath the Chroma title.
- Keeps the Anti-cheat safe, Website, GitHub, and Check updates actions in the approved layout.

## Compatibility

- Keeps all link and updater behavior unchanged.
- Keeps saturation, custom resolution, GPU selection, tray, startup, and profile behavior unchanged.
- Remains a compressed self-contained two-file Windows x64 package.
