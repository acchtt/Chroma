# Chroma v1.11.12

This release rearranges the Profiles footer to use the available width more evenly.

## Footer layout

- Separates the Anti-cheat safe badge from the right-side action-button group.
- Centers the safety badge in the flexible middle section of the footer.
- Keeps Website, GitHub, and Check updates grouped consistently on the right.
- Reduces unnecessary empty space between the branding block and utility controls.
- Slightly tightens action widths while preserving 44 px control height and centered content.
- Keeps the Chroma logo, title, creator credit, divider, and all footer actions vertically aligned.

## Compatibility

- Keeps all Website, GitHub, updater, profile, saturation, custom-resolution, GPU, tray, startup, and anti-cheat behavior unchanged.
- Remains a compressed self-contained two-file Windows x64 package.
