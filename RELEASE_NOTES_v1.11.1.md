# Chroma v1.11.1

This hotfix corrects the custom-resolution editor layout introduced in v1.11.

## Fixes

- Prevents the custom-resolution panel from replacing the entire profile editor.
- Restores the selected game's icon, name, executable path, saturation controls, and Save/Cancel buttons.
- Keeps the working custom-resolution switch and width/height fields inside the original reserved panel.
- Preserves all v1.11 display switching, refresh-rate, restoration, GPU backend, updater, and profile behavior.

## Package

- Compressed self-contained Windows x64 release.
- Portable two-file distribution containing `Chroma.exe` and `Chroma.Agent.exe`.
