# Chroma v1.10.3

This visual polish release redesigns the anti-cheat safety header on the About page.

## Changes

- Replaces the thin detached status capsule with a full-width integrated header panel.
- Adds a dedicated shield icon tile for faster visual recognition.
- Improves title and subtitle hierarchy.
- Adds a compact two-line status panel showing **Low risk** and **Architecture review**.
- Keeps the full anti-cheat explanation, technical details, and no-certification disclaimer unchanged.
- Preserves the compressed self-contained two-file portable package.

## Compatibility

- Existing profiles, settings, GPU selection, and updater behavior are unchanged.
- Intel IGCL, NVIDIA NVAPI, and AMD ADLX backends are unchanged.
- The release remains portable on supported Windows 10 and Windows 11 x64 systems.
