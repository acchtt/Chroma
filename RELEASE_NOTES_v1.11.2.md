# Chroma v1.11.2

This release applies the approved Profiles-page reorganization to the current WinUI application without changing profile behavior.

## Interface organization

- Expands the default workspace to better support the profile list and editor side by side.
- Uses a wider, better-spaced navigation rail with a cleaner compact monitoring card.
- Enlarges profile cards, icons, titles, saturation values, and enable controls for easier scanning.
- Gives the profile editor more width and clearer spacing between the game header, saturation controls, custom resolution, and actions.
- Makes the drag-and-drop area and footer better proportioned to the main workspace.
- Keeps Quick Actions and About Chroma in the existing footer, matching the approved concept.

## Preserved behavior

- Existing profiles, names, icons, enabled states, and saturation values are unchanged.
- Custom resolution switching, refresh-rate preservation, and desktop-mode restoration are unchanged.
- GPU selection, updater behavior, anti-cheat disclosure, tray operation, and startup support are unchanged.
- The release remains a compressed self-contained Windows x64 package containing only `Chroma.exe` and `Chroma.Agent.exe`.
